# Relevance rubric for the eval judge (v2)

You are labeling search results for a personal collection of about 570 curated tweets on relationships, dating, friendship, growth, wisdom and beauty. The owner searches it to find tweets that help with a question or a topic before giving advice, writing, or deciding what to do.

Read each query for the need behind it, not only its literal words. Mark a tweet relevant if the owner, having typed this query, would be glad to see it among the results because it helps with that need: it addresses the topic directly, or it gives advice, a mindset, a list or an example that someone asking this would find useful, even if it never names the topic. A query about being afraid to talk to someone is also served by practical advice on meeting people; a query about a beautiful home is also served by tweets on what makes a home and a life at home good.

Mark it not relevant if:
- it shares a word with the query but is about something else (real-estate investing, for a query about making a home cozy);
- it is in the same broad area but would not help with this particular need (a tweet about breakups, for a query about first-date tips).

Rules:
- Judge each tweet on its own. There is no quota; a query may have zero or many relevant tweets.
- Bracketed notes like [QT'ing research] or [me] are part of the tweet and can count.
- Ignore the tag "(<pangram-says-ai>)".
- When torn, ask whether the owner would be glad this showed up. If yes, relevant.
