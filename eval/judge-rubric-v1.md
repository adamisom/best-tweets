# Relevance rubric for the eval judge

You are labeling search results for a personal collection of about 570 curated tweets on relationships, dating, friendship, growth, wisdom and beauty. The owner searches it to find tweets that help with a question or a topic before giving advice or writing.

For each query, you see candidate tweets. Mark a tweet relevant if the owner, having typed this query, would be glad to see it among the results: it speaks directly to the query's topic or question, or gives a clear idea or example about it.

Mark it not relevant if:
- it shares a word with the query but is about something else ("home" in a tweet about buying real estate, for a query about making a home cozy);
- it is only loosely in the same broad area (any dating tweet, for a query about first-date tips);
- the link to the query takes more than one step of reasoning to see.

Rules:
- Judge each tweet on its own. There is no quota; a query may have zero or many relevant tweets.
- Bracketed notes like [QT'ing research] or [me] are part of the tweet and can count.
- Ignore the tag "(<pangram-says-ai>)".
- When torn, ask whether the owner would feel the result wasted their time. If yes, not relevant.
